# Chess

A browser-based chess game.

## Project files

- `index.html` — page structure and game interface
- `styles.css` — layout, board, pieces, and responsive styling
- `script.js` — chess rules, game logic, and AI behavior

## Run locally

No build step or package installation is required.

1. Open this folder in VS Code.
2. Start **Live Server** from `index.html`, or open `index.html` directly in a browser.
3. The game runs locally in the browser.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Add and commit all files in this folder.
3. Push the `main` branch to GitHub.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.

GitHub Pages will publish the site using `index.html` as the entry point.

## Notes

- The project uses plain HTML, CSS, and JavaScript.
- There are no external libraries or build tools required.
- The page's existing 90% layout scaling has been preserved.
