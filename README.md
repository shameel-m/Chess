# Chess

A browser-based chess game.

## Project files

- `index.html` — page structure and game interface
- `styles.css` — layout, board, pieces, and responsive styling
- `script.js` — chess rules, game logic, and AI behavior

## Run locally

No build step or package installation is required.

1. Open this folder in VS Code.
2. Start **Live Server** from `index.html`, or open `index.html` directly in a browser.
3. The game runs locally in the browser.
